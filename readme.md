### SOFTWARE ENGINEERING - DESIGN PATTERNS

#### Instruções
* Comportamentais: Strategy, Observer, 
* Criacional: Factory,
* Estruturais: Adapter e Decorator

1. peguem o maior condicional por tipo do projeto de vocês 

2. Desenhem o diagrama de sequência de um cenário que passa por ele — só objetos e mensagens

3. Respondam em uma frase: que variação um padrão absorveria ali?

4. Escolham um: Strategy, Factory Method, Observer, Adapter, Decorator — ou “nenhum ainda”

5. Vale responder “nenhum”: não aplicar também é decisão, e ela vai para o ADR
